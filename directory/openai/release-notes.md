# Bridle — initial directory release notes (draft)

- Connect to Bridle's hosted MCP server using OAuth 2.1 and PKCE.
- Inspect owner-signed spending mandates and their approved recipients and caps.
- Run a payment eligibility check without submitting a proposal.
- Submit proposals on supported testnets and inspect proposal status.
- Discover live testnet networks and retrieve receipts for executed proposals.
- No owner-control tools are exposed.
- Current supported rails: NEAR testnet native NEAR and Base Sepolia USDC. Solana is planned, not live.
- A cleared proposal is not necessarily an executed transfer.

This release note is a draft. Confirm the production endpoint and all listed behaviors after the final reviewer test run.
