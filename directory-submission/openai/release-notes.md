# Bridle directory package — 0.1.0 (draft)

- Packages Bridle's hosted MCP endpoint at `https://bridle-agent.vercel.app/mcp`.
- Declares Streamable HTTP and OAuth 2.1 / PKCE with dynamic client registration.
- Documents the nine agent tools and their owner-controlled boundaries.
- States supported rails accurately: NEAR testnet, Base Sepolia USDC and native NEAR; Solana is planned.
- Includes draft positive and negative reviewer scenarios.
- Includes a square monochrome Bridle icon.

This is not a production/mainnet payment product and the package is not ready for submission until reviewer tests, a public walkthrough, publisher verification and final legal pages are complete.
